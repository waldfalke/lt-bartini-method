# lt-bartini-method

**License:** [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) — free for non-commercial use, **commercial use requires the author's permission** · **Author:** [@waldfalke](https://github.com/waldfalke) · **Language:** Russian · **Runtime deps:** none

An agent skill for resolving engineering and inventive contradictions with the LT method of
Bushuev–Bartini–Kuznetsov. Conflicting factors are assigned physical dimensions `LᵐTⁿ` from
Bartini's table, multiplied under "AND-AND" logic; the x-element is read off the resulting trend.
Plain Markdown — no scripts, no network calls, no MCP servers, works offline. Content is in Russian.

## Установка

Каталог должен называться `lt-bartini-method` — имя каталога обязано совпадать с полем `name` во
фронтматтере `SKILL.md`, иначе скилл не подхватится.

**Claude Code, пользовательская область** (доступен во всех проектах):

```bash
git clone https://github.com/waldfalke/lt-bartini-method \
  ~/.claude/skills/lt-bartini-method
```

Windows PowerShell:

```powershell
git clone https://github.com/waldfalke/lt-bartini-method `
  "$env:USERPROFILE\.claude\skills\lt-bartini-method"
```

**Claude Code, область проекта** (только для одного репозитория — и тогда скилл поедет вместе с ним):

```bash

  .claude/skills/lt-bartini-method
```

**Любой другой агент.** Зависимостей нет, ставить нечего: положить каталог куда угодно и дать
агенту прочитать `SKILL.md` — это единственная точка входа. Остальные файлы он подтянет сам по
таблице внутри.

Обновление: `git pull` в каталоге скилла. Удаление: удалить каталог.

## Проверка, что встало

Перезапустить сессию агента и дать запрос с любым из триггеров — «реши по Бартини», «LT-метод»,
«разреши противоречие через размерности». В Claude Code скилл виден в списке как
`lt-bartini-method`; можно вызвать напрямую по имени.

Признак, что скилл работает, а не пересказывается по памяти: агент называет размерности `LᵐTⁿ`
конкретных факторов, показывает произведение «И-И» и ведёт по тренду **несколько** ячеек, а не
выдаёт одно решение прозой.

## Агенту, который это читает

Точка входа — **`SKILL.md`**. Читать его целиком, остальное грузить по нужде, а не превентивно:
корпус рассчитан на подгрузку по ходу рассуждения.

| Файл | Когда открывать |
|---|---|
| `SKILL.md` | всегда — ход рассуждения, что считается результатом, границы |
| `bartini-table.md` | назначение размерностей и чтение икс-элемента |
| `si-to-lt.md` | перевод единиц СИ в `LᵐTⁿ` — воспроизводимое ядро шага «размерности» |
| `trends.md` | тренды, гены, правило знака, «тренд как меню рычагов» |
| `examples/` | калибровка на разобранных задачах — сверяться, не цитировать вслепую |
| `antipatterns.md` | **до выдачи ответа**; дополнять, когда поймал новый сбой |
| `epistemics.md` | обязательно в нефизическом, смысловом домене — там действует риск зеркала |
| `threads.md` | активные нити: открытия, не выводы |
| `*-source.png` | изображения-первоисточники (таблица Бартини, рисунок трендов) для сверки |

Метод даёт **кандидатов, а не готовые решения**. Ближайшая ячейка тренда — очевидный
икс-элемент, и часто на нём правильно остановиться. Дальние ячейки — другая физика при том же
законе сохранения; это рычаги, которые человек обязан взвесить по TRL, стоимости, рискам и
реализуемости. Не выдавать их за готовое и не обесценивать очевидное ради «креатива».

## Что это за метод

Противоречие не лечится компромиссом — оно снимается икс-элементом с определённой размерностью.
Метод указывает не точку, а тренд: диагональ вещественно-полевых ресурсов, где ячейки размерно
эквивалентны, но физически различны. Неочевидные решения живут на дальних ячейках того же тренда,
куда обычная предметная интуиция не доходит. В отличие от АРИЗ, метод работает с несколькими
факторами сразу, а не с парой.

**Сам метод автору этого репозитория не принадлежит.** Кинематическая система физических величин —
Р. О. Бартини; развитие и приложение к задачам — П. Г. Кузнецов и Ю. С. Бушуев; часть эталонных

воспроизводимый перевод СИ → `LᵐTⁿ`, чтение тренда как меню рычагов, свод антипаттернов,
эпистемический слой с явно названными открытыми ставками и разборы задач за пределами известных
эталонов. Изображения `*-source.png` воспроизводят первоисточники и приложены для сверки.
